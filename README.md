# 王者荣耀隐藏战绩查询与长期监测

一个专注于**王者荣耀隐藏战绩查询**与**长期战绩监测**的服务。

## 说明：查询方式

- **隐藏战绩一样查得到。** 即使对方开启了隐藏战绩，只要该账号已经在监测中，战绩同样可以获取。
- **前提是必须先建立观测任务。** 监测只从任务建立那一刻开始记录；**任务建立之前**的历史对局查询不到。
- 所以想查哪个账号，尽早把它加进监测——建立得越早，能覆盖到的对局越完整。

## 功能概览

- **隐藏战绩查询**：即使对方关闭了战绩展示，只要已建立观测任务，其战绩依然可以获取
- **持续监测**：对指定账号进行长期跟踪，实时掌握其战绩动态变化
- **记录留存**：自动留存监测期间的对局记录，支持随时回溯与对比
- **覆盖范围**：仅包含观测任务建立之后产生的对局

## 使用入口

Telegram 机器人：**[@wzry_mobot](https://t.me/wzry_mobot)**

直接对机器人发送指令即可使用：

- `/new <营地ID>` — 创建监测任务（营地 ID 是王者营地个人主页里的那串数字）
- `/tasks` — 查看我的全部监测任务
- `/battles` — 查看已观测到的对局
- `/balance` — 查询积分余额
- `/recharge <充值码>` — 充值积分
- `/help` — 查看完整指令说明
