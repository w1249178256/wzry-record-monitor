# 王者荣耀隐藏战绩查询与长期监测

一个专注于**王者荣耀隐藏战绩查询**与**长期战绩监测**的服务。

## 功能概览

- **隐藏战绩查询**：支持查询玩家的隐藏战绩数据，即使对方关闭了战绩展示也能获取相关信息
- **长期监测**：对指定玩家进行持续跟踪监测，实时掌握其战绩动态变化
- **记录留存**：自动留存历史战绩记录，支持随时回溯与对比
